# Antimatter community

Welcome! This is the place to report bugs, ask for features, ask questions and talk about
[Antimatter](https://antimatter.chat).

Antimatter is a self-hosted chat platform for communities and teams: channels, direct messages,
threads, voice and video calls, and a growing set of apps such as notes, a whiteboard, kanban
boards, polls, a calendar and mail. It is a fully open source fork of Mattermost, with every feature
available without a license key. You run it on your own server, and your data stays with you.

## Where things go

| You want to... | Go to |
| --- | --- |
| Report a bug | [Open an issue](https://github.com/AntimatterChat/community/issues/new/choose) and pick **Bug report** |
| Ask for a feature | [Open an issue](https://github.com/AntimatterChat/community/issues/new/choose) and pick **Feature request** |
| Ask for a plugin or an integration with another tool | [Open an issue](https://github.com/AntimatterChat/community/issues/new/choose) and pick **Plugin or integration request** |
| Ask a question or get help with your setup | [Discussions: Q&A](https://github.com/AntimatterChat/community/discussions/categories/q-a) |
| Share an idea you'd like to talk through first | [Discussions: Ideas](https://github.com/AntimatterChat/community/discussions/categories/ideas) |
| Show what you built, or just chat | [Discussions](https://github.com/AntimatterChat/community/discussions) |
| Report a security problem | **Never in a public issue.** Use [private vulnerability reporting](https://github.com/AntimatterChat/community/security/advisories/new) and read the [security policy](https://github.com/AntimatterChat/community/security/policy) |

Not sure whether it's a bug or a question? Start a discussion. We can turn it into an issue later.

Before you open something new, please search the existing
[issues](https://github.com/AntimatterChat/community/issues) and
[discussions](https://github.com/AntimatterChat/community/discussions). If you find yours, add a
thumbs-up reaction or a comment with your details: that helps us see what matters most.

## What happens next

1. Every new issue gets the `status/triage` label. A maintainer reads it, adds an `area/...` label
   for the part of Antimatter it's about, and may ask for more details (`status/needs-info`).
2. Then it becomes `status/accepted` (we agree it should be done), `status/planned` (it's on the
   roadmap) or `status/wontfix` (with an explanation).
3. Once the work starts, the issue may be **moved to the code repository** concerned (the server,
   a plugin, the apps...). GitHub keeps a redirect, so your link keeps working and you stay
   subscribed.

Issues labelled `good first issue` or `help wanted` are a great way to start contributing.

## The main repositories

- [antimatter](https://github.com/AntimatterChat/antimatter): the server and the web apps
- [antimatter-docker](https://github.com/AntimatterChat/antimatter-docker): the Docker image, with
  the plugins bundled, and a compose file to run it
- [desktop-app](https://github.com/AntimatterChat/desktop-app),
  [mobile-app](https://github.com/AntimatterChat/mobile-app) and
  [push-proxy](https://github.com/AntimatterChat/push-proxy): the apps and their push notification
  service
- Plugins: [all `antimatter-plugin-*` repositories](https://github.com/orgs/AntimatterChat/repositories?q=antimatter-plugin)
- [antimatter.chat](https://github.com/AntimatterChat/antimatter.chat): the website

What we're working on next is on the
[Antimatter roadmap](https://github.com/orgs/AntimatterChat/projects/1).
